# LSTM Music Generator

A neural network that learns patterns from MIDI music and generates new musical sequences using an LSTM.

## Goal

This project is being built to learn:

- Recurrent Neural Networks
- LSTMs
- Sequence modeling
- MIDI processing
- Autoregressive generation
- Neural network training with TensorFlow/Keras

## How It Works

The model learns to predict the next musical note or chord based on a sequence of previous notes.
